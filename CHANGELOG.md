# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-12

- First version of the `pfte-translations` skill: list the languages of a SharePoint site, check the translation status of a page or document, translate it, and find the pages with outdated translations, through the PointFire Translator Express tools on the page
- Claude Code plugin which installs the skill together with its own Chrome DevTools MCP server, `pointfire-browser`, using a separate Chrome profile
- Release packages for the other AI tools: `pfte-translations.zip`, and `pfte-translations.skill` for the Claude apps
